## Инструкции по запуску

1. Установить зависимости:
```bash
npm install
```

2. Запустить приложение:
```bash
npm start
```

Приложение откроется по адресу [http://localhost:3000](http://localhost:3000)

## Доработки на 9-10 баллов

### Оптимизация производительности
- Использование React.memo для компонента PetCard для предотвращения лишних ререндеров
- Мемоизация всех колбэков через useCallback
- Мемоизация списков через useMemo (фильтрация питомцев, список видов)

### Улучшенный UX
- Анимация аватара при изменении настроения/энергии через useRef
- Динамическая тень карточки в зависимости от настроения питомца (inline styles)
- Плавные переходы и hover-эффекты
- Адаптивная сетка с использованием CSS Grid (1/2/3 колонки в зависимости от размера экрана)

### Архитектура
- Вынесение логики жизненного цикла питомца в кастомный хук usePetLifecycle
- Кастомный хук useEventLog для удобной работы с контекстом
- Типизация всех компонентов через TypeScript
- Разделение типов в отдельный файл types.ts

### Стилизация
- Использование всех требуемых типов стилизации:
  - SCSS (глобальные стили)
  - CSS Modules (стили карточки)
  - Inline styles (динамическая тень)
  - styled-components (кнопки действий)
  - Material UI (компоненты интерфейса)
